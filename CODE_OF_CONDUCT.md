# Code of Conduct

Forge Agent is intended to be a welcoming open-source project for people building ordinary-user automation.

## Expected behavior

- Be respectful and constructive.
- Assume good intent, but accept corrections quickly.
- Keep discussions focused on the project and its users.
- Report bugs with enough detail for maintainers to reproduce them.
- Respect privacy and do not post secrets, credentials, private files, or sensitive user data.

## Unacceptable behavior

- Harassment, insults, or discriminatory language.
- Posting private information without permission.
- Encouraging unsafe use of automation against other people or systems.
- Misrepresenting project maturity, security status, or production readiness.

## Enforcement

Maintainers may edit, hide, or remove comments and may block contributors who repeatedly violate this code. Security issues should be reported privately according to `SECURITY.md`.
